# Captain Falcon controller publication notice

`falcon_locomotion.*` is directly ported from the Super Smash Bros. 64
decompilation at `VetriTheRetri/ssb-decomp-re`, pinned to
`054ffc23f396868cd1db2b87ee3a2c1d3bebb75a`.

That upstream repository did not publish a license when this code was first
ported. This project preserves the upstream attribution and treats reuse as a
project release-policy decision, not a verified upstream license grant or legal
conclusion. Revisit the decision if upstream licensing information changes.

No source in this directory includes a ROM, ROM slice, extracted animation,
texture, audio, owner-ROM path, or cache. The SMW host receives symbolic move
and audio intent only.
