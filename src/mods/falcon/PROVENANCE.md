# Captain Falcon controller provenance

`falcon_locomotion.*` was ported from
[`VetriTheRetri/ssb-decomp-re`](https://github.com/VetriTheRetri/ssb-decomp-re)
at revision `054ffc23f396868cd1db2b87ee3a2c1d3bebb75a`.

The upstream repository had no published license when this code was first
ported. Preserve the upstream credit and pinned revision in any release that
contains this source, and revisit the release decision if upstream licensing
information changes.

This directory contains no Super Smash Bros. 64 ROM data, ROM slices, decoded
assets, animation data, textures, audio, owner-ROM paths, or caches. The
controller exports only symbolic audio-cue bits for a host mapping.
